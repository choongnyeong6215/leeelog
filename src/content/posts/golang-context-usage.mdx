`context.Context`를 함수 시그니처 첫 번째 인자로 받는 관례는 처음엔 번거로워 보이지만, 취소 전파를 다룰 땐 필수다.

## 타임아웃 설정

```go
ctx, cancel := context.WithTimeout(context.Background(), 3*time.Second)
defer cancel()

req, _ := http.NewRequestWithContext(ctx, "GET", url, nil)
resp, err := http.DefaultClient.Do(req)
```

`defer cancel()`을 빼먹으면 타이머 리소스가 함수 종료 후에도 남아있을 수 있으므로 항상 짝을 맞춰야 한다.

## 취소 전파

상위 컨텍스트가 취소되면 거기서 파생된 모든 하위 컨텍스트도 함께 취소된다. HTTP 핸들러에서 요청이 끊기면, 그 안에서 시작한 DB 쿼리나 하위 호출도 `ctx.Done()`을 통해 취소 신호를 받을 수 있다.

## context.Value는 최소한으로

```go
ctx = context.WithValue(ctx, requestIDKey, "abc-123")
```

`context.Value`는 요청 ID, 트레이싱 정보처럼 요청 스코프의 부가 데이터를 전달하는 용도로만 쓰고, 함수의 필수 파라미터를 여기 숨기지 않는 게 좋다. 타입 안정성이 없어서 컴파일 타임에 실수를 잡아주지 못하기 때문이다.
