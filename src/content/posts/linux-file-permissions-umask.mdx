리눅스에서 새 파일을 만들 때마다 권한이 "왜 이렇게 나왔지"라는 의문이 든다면, umask를 먼저 이해해야 한다.

## rwx와 8진수

`ls -l` 결과의 `rwxr-xr--` 같은 문자열은 소유자/그룹/기타 사용자 순서로 읽기(r)·쓰기(w)·실행(x) 권한을 나타낸다. 각 3비트를 8진수 한 자리로 압축하면 `754` 같은 익숙한 숫자가 된다.

```bash
chmod 754 deploy.sh
# rwx r-x r--
```

## umask는 "빼는" 값이다

새 파일/디렉터리가 만들어질 때 기본 권한(파일 666, 디렉터리 777)에서 umask 값을 뺀 결과가 최종 권한이 된다.

```bash
umask
# 0022
touch new.txt
ls -l new.txt
# -rw-r--r--  (666 - 022 = 644)
```

## 실전 팁

배포 스크립트나 설정 관리 도구에서 `umask 027`처럼 그룹/기타 사용자 쓰기 권한을 원천 차단해두면, 이후 실수로 권한을 열어둔 파일이 생기는 사고를 줄일 수 있다.
